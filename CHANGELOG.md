# Changelog

## 0.3 — 2026-11-25
- Вкладка «Аналитика»: 7 карточек — тренд (Theil–Sen + Mann–Kendall), прогноз (Kalman),
  перелом уровня, радар «Профиль специалиста», предметы (байесовская усадка + BH–FDR),
  прогулы по дням недели, лаг-эффект прогулов на оценки
- Тап по карточке — страница с методикой, инфографикой (графики на Canvas) и выводами
- Блок «ВНИМАНИЕ» — сигналы для родителей: просроченные ДЗ, прогулы за 2 недели,
  низкая посещаемость, снижение оценок, свежие ≤3
- Отпуск/больничный: периоды в настройках (добавить/изменить/удалить),
  прогулы в них не считаются (серые курсивом в таблице), оценки сохраняются
- Новые оценки подсвечиваются (в т.ч. поставленные задним числом), гаснут после просмотра
- Бейдж иконки очищается при открытии приложения
- Опция «Показывать сданные ДЗ» (внизу списка, полупрозрачные)
- Виджет: шрифт ×0.8 / ×1.4, тап по дате = синхронизировать сейчас
- Таблица оценок: компактные строки (26/38dp), оценки крупнее (12sp)
- Виджет синхронизируется при системной перерисовке (обход Samsung Doze)
- Страницы-пояснения: методика + инфографика + развёрнутые выводы для всех метрик

## 0.2 — 2026-11-19
- Адаптивная ширина колонки предметов: при построении таблицы подбирается ширина, при
  которой ~80% названий помещаются в одну строку; длинные переносятся на вторую
  (высота строки автоматически 40/52 dp)
- В горизонтальной ориентации вкладки переезжают в шапку (между именем и «Обновить») —
  на экран влезает больше строк таблицы
- Под таблицей итоги: «ИТОГО прогулов: X / опозданий: X» + разбивка по предметам
- Виджет: расписание на сегодня (только непрошедшие уроки) и завтра
- Виджет: строки ДЗ — просроченные красным + ближайшая неделя, тема курсивом
- Самообновление из GitHub Releases: модалка «Доступно обновление»
  (версия/дата/список изменений), кнопки «Скачать и установить / Пропустить версию / Позже»
- Настройки (тап по имени студента): размер шрифта виджета — малый/средний/большой
- Фикс загрузки файлов ДЗ: fs.top-academy.ru редиректит на S3 без Content-Type —
  теперь резолвим редирект, достаём имя файла и задаём корректный MIME по расширению
- Тёмная/светлая тема по системе; модалки предмета и ДЗ (открытие файлов);
- CI: APK на каждый пуш, Release с APK на тег vX.Y
- Диета APK: 9.5 МБ → 3.6 МБ — только arm64, без AOT-образов (RunAOTCompilation=false),
  тримминг BCL, инвариантная глобализация (без ICU), JSON через Source Generator
- Package ru.erambler.topjournal (вместо ru.family)
